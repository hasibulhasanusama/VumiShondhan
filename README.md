# VumiShondhan — Frontend

A responsive Bangla-first frontend prototype for VumiShondhan (ভূমি সন্ধান), a proposed land information and verification support platform.

## Run it
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser. No build tools are required.
3. For local development, you can use VS Code Live Server.

## Included
- Intro logo screen using the provided VumiShondhan logo
- Responsive navigation and Bangladesh rural-inspired hero/background image
- Land service cards based on the supplied functional requirements
- Land search demo form with client-side validation
- Login, sign-up and support modal prototypes
- FAQ, verification status guide and how-it-works section
- Frontend-only land assistant with general sample answers
- Links to the official land information portal

## Important
This is **frontend only**. Forms do not create accounts, upload documents, query government records, or store data. The assistant uses preset demo answers, not a live AI service. It is not an official government website and does not claim government approval or ownership verification. Before production, implement a secure backend, approved data integrations, authentication, private document storage, privacy controls, and audit logging.

The official portal linked in this prototype is https://land.gov.bd/.
